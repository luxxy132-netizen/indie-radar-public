어떻게 고르나

"내가 좋아하는 태그가 붙었다"만으로는 부족합니다. Indie · Casual처럼 누구에게나 붙는 태그는 아무것도 말해 주지 않으니까요.

1

내 취향 태그

스팀 라이브러리에서 오래 한 게임(소프트웨어 제외)과 좋아하는 게임 링크의 공식 태그 중, 여러 게임에 공통으로 나오는 것.

2

이번 주에 드문 태그

그 주 신작의 10% 이하에만 붙은 태그. 드물수록 점수가 높고, 흔한 태그는 거의 0점.

3

2개 이상 겹치면 추천

드문 취향 태그가 2개 이상 겹친 신작만, 점수순 최대 10개. 약한 주엔 억지로 채우지 않습니다.

조용히 실패하지 않는다

자동화에서 제일 무서운 건 "돌긴 도는데 틀린 것"입니다.

  • 실패하면 GitHub 이슈수집 · 점검 · 취향 갱신 · 발송 중 하나라도 실패하면 무엇이 왜 실패했는지 이슈로 남깁니다.
  • 한 사람의 실패는 그 사람에서 끝누군가의 DM이 실패해도 다른 사람은 받습니다. 스팀 프로필이 비공개로 바뀌면 지난 취향으로 보내고 알립니다.
  • 점검을 통과한 데이터만 쓴다매일 15항목(누락 · 중복 · 가격 · 태그 · 출시일 …)을 점검하고, 오늘 것이 실패하면 적재하지 않습니다.
  • 기록은 덮어쓰지 않는다날짜가 붙은 원본 · 점검 결과 · 리포트는 다시 돌려도 -2, -3으로 새로 남습니다.
  • 비밀값은 어디에도 남지 않는다스팀 키 · 슬랙 토큰은 GitHub Secrets에만. 오류 기록엔 예외 종류와 HTTP 코드만 남기고, 이를 테스트로 확인합니다.

직접 써 보기

자세한 내용은 저장소의 README에 있습니다.

  1. 저장소를 가져갑니다(Fork 또는 코드 복사). 명단에 슬랙 ID가 들어가니 비공개 저장소를 권합니다.
  2. Settings → Secrets에 SLACK_BOT_TOKEN(슬랙 앱, chat:write)과 STEAM_API_KEY를 넣습니다.
  3. Settings → Variables에 RADAR_ENABLED = true를 넣으면 매일 수집이 켜집니다.
  4. subscribers.yaml에 슬랙 멤버 ID와 스팀 프로필 주소를 적습니다. 일주일 뒤 월요일에 첫 DM이 옵니다.
